Onde registrar

Antes de o Alpine iniciar: num <script> entre alpine-form.min.js e o Alpine (com defer), ou antes de Alpine.start() no ESM. Registrar um nome que já existe é erro; para substituir de propósito, passe { replace: true } como terceiro argumento.

Regra simples

@@@js AlpineForm.validator('placa', { validate: value => /^[A-Z]{3}-?\d[A-Z0-9]\d{2}$/.test(String(value).toUpperCase()), }) AlpineForm.messages.placa = 'Informe uma placa no padrão antigo (ABC-1234) ou Mercosul (ABC1D23).' @@@ @@@html @@@

Retornos aceitos: true (válido), false (inválido, usa a mensagem configurada), um texto (inválido, usado como mensagem se não houver uma configurada) ou { valid: false, vars: { … } } com valores extras para a mensagem. A regra não roda com o campo vazio — required cuida disso.

Regra com parâmetros

@@@js AlpineForm.validator('idade_minima', { params: [{ name: 'anos', type: 'integer' }], validate(value, ctx) { const nascimento = new Date(value + 'T00:00:00') const limite = ctx.clock() limite.setFullYear(limite.getFullYear() - ctx.params.anos) return nascimento <= limite }, }) AlpineForm.messages.idade_minima = 'Você precisa ter pelo menos :anos anos.' @@@ @@@html @@@

Tipos de parâmetro: integer, number (decimal como texto), size ({ bytes, text }), field ({ ref }, cria dependência), date-or-field, enum (com values: [...]), string. Use optional: true para opcionais e rest: { name, type, min } para listas (regra:a,b,c). Parâmetro inválido vira erro de configuração com mensagem clara.

Regra que olha outro campo

@@@js AlpineForm.validator('menor_que_salario', { params: [{ name: 'salario', type: 'field' }], validate(value, ctx) { const salario = ctx.other(ctx.params.salario.ref) // { value, label, ... } if (!salario.value) return true return AlpineForm.utils.compareDecimal(value, salario.value) < 0 || { valid: false, vars: { other: salario.label } } }, }) AlpineForm.messages.menor_que_salario = ':field deve ser menor que :other.' @@@ @@@html @@@

Ao mudar o salário, a parcela é revalidada automaticamente (o parâmetro do tipo field cria a dependência).

Regra assíncrona

@@@js AlpineForm.validator('cep_existe', { async: true, async validate(value, ctx) { const resposta = await fetch(`https://viacep.com.br/ws/${String(value).replace(/\D/g, '')}/json/`, { signal: ctx.signal }) if (!resposta.ok) return true // serviço fora: não bloqueia const dados = await resposta.json() return !dados.erro || 'CEP não encontrado.' }, }) @@@ @@@html @@@
  • Regras assíncronas só rodam se as síncronas passaram.
  • Passe ctx.signal para o fetch: se a pessoa digitar de novo, a consulta anterior é cancelada e o resultado antigo descartado.
  • Para consultar o seu servidor, prefira data-form-remote (já tem cache, debounce e política de falha).

O objeto ctx

MembroConteúdo
ctx.paramsParâmetros convertidos, pelo nome.
ctx.field{ name, label, kind, … } do campo.
ctx.other(nome)Valor e dados de outro campo.
ctx.signalAbortSignal da validação.
ctx.clock()Data atual (substituível em testes com configure({ clock })).
ctx.attribute(nome)Lê um atributo do campo.
ctx.configError(msg)Marca configuração inválida.

Normalizador

Transforma o valor usado na validação e no envio, sem mudar o que aparece na tela. Embutidos: trim, lowercase, uppercase, digits, collapse_spaces, decimal[:locale].

@@@js AlpineForm.normalizer('sem_acentos', value => typeof value === 'string' ? value.normalize('NFD').replace(/[̀-ͯ]/g, '') : value) @@@ @@@html @@@

Componente próprio

Qualquer widget que não é um input (editor rico, estrelas, seletor de cor, mapa) participa da validação e do envio com um adaptador:

@@@js AlpineForm.component('editor', { getValue: el => el.querySelector('[contenteditable]').innerHTML.trim(), setValue(el, value) { el.querySelector('[contenteditable]').innerHTML = value ?? '' }, subscribe(el, notify) { const area = el.querySelector('[contenteditable]') area.addEventListener('input', notify) return () => area.removeEventListener('input', notify) // obrigatório: limpeza }, }) @@@ @@@html
@@@

Transporte próprio

Muda como a requisição é feita (axios, autenticação especial, mock em testes):

@@@js AlpineForm.transport('axios', async request => { const resposta = await axios({ url: request.url, method: request.method, headers: request.headers, data: request.body, signal: request.signal, timeout: request.timeout || 0, withCredentials: request.credentials === 'include', onUploadProgress: e => request.onUploadProgress?.({ loaded: e.loaded, total: e.total, lengthComputable: !!e.total }), transformResponse: r => r, // texto cru: o AlpineForm interpreta validateStatus: () => true, // erros HTTP também são respostas }) request.onUploadComplete?.() return { status: resposta.status, statusText: resposta.statusText, url: request.url, redirected: false, headers: { get: nome => resposta.headers[nome.toLowerCase()] ?? null }, text: typeof resposta.data === 'string' ? resposta.data : JSON.stringify(resposta.data), } }) @@@ @@@html
@@@

Registrar um transporte com o nome remote, job ou chunk faz a validação remota, o acompanhamento de jobs ou o upload em partes usá-lo.

Erros de rede devem ser lançados com kind: 'network' (ou 'timeout') e cancelamentos com name: 'AbortError', para a biblioteca classificar corretamente.

Adaptador de UI

Para trocar só as classes CSS, veja Interface. Para controlar todo o HTML gerado, registre uma fábrica que devolve um objeto com renderField(field, view), removeField(field), renderSummary(view), focusSummary(), renderFileList(field, container, items, { onRemove }), renderExisting(entry), setDropzoneOver(el, over) e destroy():

@@@js AlpineForm.uiAdapter('meu', ({ form, uid, controller }) => new MeuAdaptador(form)) @@@

Marque com data-form-generated tudo que o adaptador criar e remova no destroy().

Plugin

@@@js export default function meuPlugin(AlpineForm) { AlpineForm.validator('placa', { validate: v => /^[A-Z]{3}-?\d[A-Z0-9]\d{2}$/i.test(v) }) AlpineForm.messages.placa = 'Placa inválida.' AlpineForm.fieldAttributes(['data-form-placa-uf']) // novos atributos de campo aceitos AlpineForm.formHook(controller => ({ // um objeto por formulário async beforeSend(ctx) { /* antes de montar a requisição */ }, destroy() { /* limpeza */ }, })) AlpineForm.alpine(Alpine => { // diretivas e mágicas próprias do Alpine Alpine.magic('agora', () => new Date().toLocaleString('pt-BR')) }) } AlpineForm.use(meuPlugin) // carregar duas vezes não tem efeito @@@

AlpineForm.alpine(setup) recebe o Alpine quando o plugin do AlpineForm é instalado (ou na hora, se já foi). É como o módulo de listagens registra x-lista e $lista sem exigir um Alpine.plugin() a mais.
