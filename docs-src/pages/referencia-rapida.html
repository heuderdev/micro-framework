Chaves de mensagem

Além de uma chave por regra (required, email…) e variantes (required.choice, required.multiple, required.checkbox, required.file, min.numeric, min.array, max.numeric, max.array, between.numeric, between.array, length.array, digits.length, decimal.range, date.datetime, date.time, date.month, date.week, telefone.celular, telefone.fixo, image.decode):

ChaveTexto padrão
__fallbackConfira o valor de :field.
__configEste campo tem uma configuração inválida e não pode ser validado.
remote · pendingEste valor não está disponível. · Verificando...
remote.inconclusive · remote.errorNão foi possível verificar agora. O valor será conferido no envio. · Não foi possível verificar este valor agora.
submit.networkNão foi possível conectar ao servidor. Verifique sua conexão e tente novamente.
submit.timeoutO servidor demorou demais para responder.
submit.unknownA conexão caiu depois do envio. Não é possível confirmar se a operação foi concluída; verifique antes de enviar novamente.
submit.authSua sessão expirou ou você não tem permissão. Entre novamente e tente outra vez.
submit.forbiddenVocê não tem permissão para realizar esta operação.
submit.csrfO token de segurança expirou. Recarregue a página e tente novamente.
submit.too_largeOs dados enviados excedem o limite aceito pelo servidor.
submit.rate_limitedMuitas tentativas. Aguarde um pouco e tente novamente.
submit.serverO servidor encontrou um erro. Tente novamente mais tarde.
submit.httpO servidor respondeu com um erro (HTTP :status).
submit.validation · submit.logicalConfira os campos destacados. · Não foi possível concluir a operação.
submit.html · submit.parseO servidor respondeu com uma página HTML em vez de dados… · A resposta do servidor não pôde ser interpretada.
submit.changed · submit.config · submit.serialization · submit.corsOs dados foram alterados durante a validação… · O formulário possui erros de configuração… · Não foi possível preparar os dados… · A requisição foi bloqueada pelo navegador…
