titulo: Eventos e hooks lead: Reagir a cada momento do formulário com eventos DOM (@form:success no Alpine) ou com hooks de configuração que podem alterar ou impedir o envio. ---

Como escutar

Os eventos são disparados no <form> e sobem (bubbling). Os dados ficam em event.detail.

@@@html Com Alpine
@@@ @@@js Com JavaScript document.getElementById('cadastro').addEventListener('form:success', event => { console.log('Salvo:', event.detail.result.data) }) // todos os formulários da página document.addEventListener('form:error', event => { meuMonitoramento.registrar(event.target.id, event.detail.error) }) @@@

Hooks de configuração

Funções em hooks (no AlpineForm.configure ou no objeto de x-form). Podem ser async: o envio espera.

HookRecebeUso
beforeSubmit(state, { submitter })estado do formDevolver false cancela o envio.
beforeRequest(request, state){ url, method, headers, body, … }Alterar cabeçalhos/URL antes de enviar.
afterResponse(result, state)resposta já interpretadaLog, métricas, ajustes.
reveal(campo, estadoDoCampo)elemento a focarAbrir aba/accordion/modal antes do foco.
@@@js AlpineForm.configure({ hooks: { async beforeSubmit(state) { // getValue devolve o canônico ("12000.00" mesmo com máscara de moeda) if (state.has('valor') && Number(state.getValue('valor')) > 10000) { return confirm('Valor acima de R$ 10.000. Continuar?') } }, beforeRequest(request) { request.headers['X-Tela'] = location.pathname }, afterResponse(result) { if (result.kind === 'auth') location.href = '/login' }, }, }) @@@
