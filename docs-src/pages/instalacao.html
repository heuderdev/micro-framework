Arquivos

Gere os arquivos com npm install e npm run build (ou use os que já estão em dist/) e copie para a pasta pública do seu projeto só o que for usar:

ArquivoQuando carregar
dist/alpine-form.min.jsSempre. Núcleo.
dist/alpine-form-completo.min.jsOu, no lugar do núcleo e de todos os módulos abaixo: pacote completo num script só.
dist/alpine-form-masks.min.jsSe usar data-form-mask.
dist/alpine-form-chunks.min.jsSe usar data-form-chunked (upload em partes).
dist/alpine-form-inspectors.min.jsSe usar as regras csv, csv_headers, json, pdf_signature, xlsx_signature, media_duration_*.
dist/alpine-form-rascunho.min.jsSe usar data-form-rascunho (rascunho automático).
dist/alpine-form-opcoes.min.jsSe usar data-form-opcoes (selects dependentes).
dist/alpine-form-preencher.min.jsSe usar data-form-preencher (autopreenchimento: CEP, CNPJ).
dist/alpine-form-avisos.min.jsSe usar data-form-avisos, data-form-confirmar, $avisos ou $confirmar (avisos e confirmação).
dist/alpine-form-autocompletar.min.jsSe usar data-form-component="autocompletar" (autocompletar).
dist/alpine-form-lista.min.jsSe usar x-lista ou data-form-lista (listagens).
dist/alpine-form-bootstrap.min.jsSe a página usa Bootstrap 5 e você quer data-form-ui="bootstrap".
css/alpine-form.cssOpcional: estilo mínimo para erros, resumo, lista de arquivos e barra de progresso (dispensável com Bootstrap).
Alpine.js 3Sempre. Não vem junto: use node_modules/alpinejs/dist/cdn.min.js ou a cópia que seu projeto já tem.

Cada módulo existe em três versões: .min.js (produção), .js (mesmo código legível, para depurar) e .esm.js (para import).

Pacote completo (um script só)

@@@html @@@ @@@js ESM import Alpine from 'alpinejs' import AlpineFormPlugin from 'alpine-form/completo' Alpine.plugin(AlpineFormPlugin) Alpine.start() @@@

Prático para começar um projeto ou para sistemas internos: máscaras, chunks, inspetores, Bootstrap, rascunho, listagens, selects dependentes, autopreenchimento, avisos e autocompletar já carregados (266 KiB minificado, 80 KiB com gzip). Nenhum módulo muda o comportamento sozinho: cada um só age onde o atributo dele aparece. Em páginas públicas, carregar só o núcleo e os módulos usados deixa a página mais leve. Exemplo: examples/crud.php.

Ordem de carregamento

  1. alpine-form.min.js — define window.AlpineForm e espera o Alpine iniciar.
  2. Módulos opcionais — se registram em window.AlpineForm.
  3. Suas extensões e AlpineForm.configure(), se houver.
  4. Alpine.js com defer — sempre por último.
@@@html HTML puro @@@
Alpine antes do AlpineForm

Se o Alpine iniciar antes do núcleo carregar, os formulários já processados não são inicializados e o console avisa "O Alpine parece já ter sido iniciado; carregue alpine-form antes do Alpine". Ponha o Alpine por último e com defer.

Token CSRF

Duas formas, use a que o seu backend espera:

  • Meta tag + cabeçalho: com <meta name="csrf-token" content="…"> na página, todo envio para a mesma origem leva o cabeçalho X-CSRF-TOKEN. É o padrão do Laravel.
  • Campo oculto: qualquer <input type="hidden"> dentro do form é enviado normalmente. É o padrão do Joomla (HTMLHelper::_('form.token')).
@@@js Outro nome de meta ou de cabeçalho AlpineForm.configure({ csrf: { meta: 'xsrf', header: 'X-XSRF-TOKEN' } }) AlpineForm.configure({ csrf: null }) // desliga o envio automático do cabeçalho @@@

Joomla 3, 4 e 5

Copie os arquivos para media/com_seucomponente/js/ e carregue na view, nesta ordem:

@@@php tmpl/default.php use Joomla\CMS\HTML\HTMLHelper; // Joomla 3: use JHtml no lugar de HTMLHelper HTMLHelper::_('stylesheet', 'com_loja/alpine-form.css', ['version' => 'auto', 'relative' => true]); HTMLHelper::_('script', 'com_loja/alpine-form.min.js', ['version' => 'auto', 'relative' => true]); HTMLHelper::_('script', 'com_loja/alpine-form-masks.min.js', ['version' => 'auto', 'relative' => true]); HTMLHelper::_('script', 'com_loja/alpine.min.js', ['version' => 'auto', 'relative' => true], ['defer' => true]); @@@

Com 'relative' => true, o Joomla procura com_loja/alpine-form.min.js em media/com_loja/js/ (e o CSS em media/com_loja/css/).

Laravel

@@@html resources/views/layouts/app.blade.php @@@

Com a meta tag, o cabeçalho X-CSRF-TOKEN segue automaticamente. Use data-form-response-adapter="laravel" para ler o 422 de validação (exemplo de controller).

Vite / bundler (ESM)

@@@js main.js import Alpine from 'alpinejs' import AlpineFormPlugin, { AlpineForm } from 'alpine-form' import masks from 'alpine-form/masks' import chunks from 'alpine-form/chunks' import inspectors from 'alpine-form/inspectors' import bootstrap from 'alpine-form/bootstrap' import rascunho from 'alpine-form/rascunho' import lista from 'alpine-form/lista' import opcoes from 'alpine-form/opcoes' import preencher from 'alpine-form/preencher' import avisos from 'alpine-form/avisos' import autocompletar from 'alpine-form/autocompletar' import 'alpine-form/css' AlpineForm.use(masks).use(chunks).use(inspectors).use(bootstrap).use(rascunho).use(lista).use(opcoes).use(preencher).use(avisos).use(autocompletar) AlpineForm.configure({ validation: 'live' }) Alpine.plugin(AlpineFormPlugin) window.Alpine = Alpine window.AlpineForm = AlpineForm // opcional: acesso pelo console Alpine.start() @@@

Sem bundler, o mesmo funciona com <script type="module"> apontando para os .esm.js (veja examples/esm-boot.js).

Conferindo se funcionou

Abra o console do navegador na página:

@@@js Console AlpineForm.version // "1.0.0" AlpineForm.diagnose() // [] = todos os
foram inicializados AlpineForm.get('meuForm') // estado do formulário com id="meuForm" (ou null) AlpineForm.registry.names('mask') // máscaras disponíveis (vazio se o módulo não carregou) @@@

Se diagnose() listar formulários, falta x-data no form (ou num elemento acima dele), ou ele está dentro de x-ignore. Veja Erros e soluções.
