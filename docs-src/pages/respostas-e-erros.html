Formato de resposta

@@@js Sucesso HTTP 200 { "success": true, "message": "Cadastro realizado.", "data": { "id": 15 } } @@@ @@@js Erro de validação HTTP 422 { "success": false, "message": "Confira os campos destacados.", "errors": { "email": ["Este e-mail já está em uso."], "itens.1.quantidade": "Estoque insuficiente.", "": ["Seu plano não permite mais cadastros."] } } @@@
  • message (ou mensagem) aparece em [data-form-status].
  • errors: chave = campo; valor = texto ou lista de textos.
  • data fica em $form.result.data.
  • Opcionais: redirect (com data-form-redirect="response"), request_id (registrado no console em erros), job (processamento).

Resposta HTML

Se o servidor devolve uma página (geralmente a tela de login após a sessão expirar), a mensagem é "O servidor respondeu com uma página HTML em vez de dados. Isso costuma indicar sessão expirada, redirecionamento para login ou erro de proxy." e $form.error.diagnostic traz o trecho e looksLikeLogin.

  • O campo recebe o erro, fica marcado como tocado e o foco vai para o primeiro campo com erro.
  • Ao editar o campo, o erro do servidor some (data-form-server-errors="clear-on-change", padrão). Com keep, fica até o próximo envio.
  • Se a pessoa alterou o campo enquanto a resposta não chegava, o erro daquele campo é ignorado (era sobre o valor antigo).

Outro formato de API

@@@js // API que responde { ok: true, payload: {...} } ou { ok: false, fieldErrors: [{ field, msg }] } AlpineForm.responseAdapter('minha-api', (raw, ctx) => { const base = AlpineForm.registry.get('responseAdapter', 'default')(raw, ctx) let json = null try { json = JSON.parse(raw.text) } catch (e) { return base } if (!json || typeof json.ok !== 'boolean') return base const errors = {} for (const e of json.fieldErrors || []) { if (!errors[e.field]) errors[e.field] = [] errors[e.field].push(e.msg) } return { ...base, ok: json.ok, kind: json.ok ? 'success' : (Object.keys(errors).length ? 'validation' : 'logical'), message: json.mensagem || null, errors, data: json.payload ?? null, } }) @@@ @@@html @@@

Mostrar erros pelo código

@@@js const form = AlpineForm.get('cadastro') form.setErrors({ email: 'Já cadastrado.', 'itens.0.qtd': ['Mínimo 1.'] }) // como se viessem do servidor form.setErrors(['Erro geral exibido no resumo.']) form.setErrors({ cpf: 'Inválido.' }, { replace: false }) // soma aos existentes form.clearErrors('email') form.clearErrors() // todos @@@
