Backend (PHP, Joomla, Laravel)

Como escrever o lado do servidor que responde ao AlpineForm: PHP puro, controller do Joomla 3/4/5 e controller do Laravel, com validação, erros por campo, arquivos, CSRF e idempotência.

O servidor sempre valida de novo. Tudo que o navegador conferiu pode ter sido burlado.

O contrato em uma linha

Responda JSON { "success": bool, "message": "…", "errors": { "campo": ["…"] }, "data": … }, com HTTP 200 no sucesso e 422 (ou 200 com success: false) na falha. Detalhes em Respostas e erros.

PHP puro

resposta.php (funções de apoio)
<?php
function responder(array $corpo, int $status = 200): void
{
    http_response_code($status);
    header('Content-Type: application/json; charset=utf-8');
    echo json_encode($corpo, JSON_UNESCAPED_UNICODE);
    exit;
}

function sucesso(string $mensagem, $dados = null): void
{
    responder(['success' => true, 'message' => $mensagem, 'data' => $dados]);
}

function falhaValidacao(array $erros, string $mensagem = 'Confira os campos destacados.'): void
{
    responder(['success' => false, 'message' => $mensagem, 'errors' => $erros], 422);
}
cliente-salvar.php
<?php
require __DIR__ . '/resposta.php';
session_start();

// CSRF: o AlpineForm envia X-CSRF-TOKEN quando a página tem <meta name="csrf-token">
if (!hash_equals($_SESSION['csrf'] ?? '', $_SERVER['HTTP_X_CSRF_TOKEN'] ?? '')) {
    responder(['success' => false, 'message' => 'Sessão expirada. Recarregue a página.'], 419);
}

$erros = [];
$nome = trim($_POST['nome'] ?? '');
$cpf = preg_replace('/\D+/', '', $_POST['cpf'] ?? '');
if (mb_strlen($nome) < 3) $erros['nome'][] = 'Informe o nome completo.';
if (!cpfValido($cpf)) $erros['cpf'][] = 'CPF inválido.';
if (clienteExiste($cpf)) $erros['cpf'][] = 'Já existe cliente com este CPF.';

// itens[0][produto], itens[1][produto]...
foreach ($_POST['itens'] ?? [] as $i => $item) {
    if (trim($item['produto'] ?? '') === '') $erros["itens.$i.produto"][] = 'Informe o produto.';
}

if ($erros) falhaValidacao($erros);

$id = salvarCliente($nome, $cpf);
sucesso('Cliente salvo.', ['id' => $id]);
Gerando o token CSRF na página
<?php session_start(); $_SESSION['csrf'] ??= bin2hex(random_bytes(32)); ?>
<meta name="csrf-token" content="<?= htmlspecialchars($_SESSION['csrf']) ?>">

Com data-form-encoding="json", leia com json_decode(file_get_contents('php://input'), true) em vez de $_POST.

Joomla 3, 4 e 5

Formulário (tmpl)
<form x-data x-form action="<?php echo JRoute::_('index.php?option=com_loja&task=cliente.salvar'); ?>"
      method="post" data-form-response-adapter="joomla" novalidate>
    <input name="jform[nome]" data-form-label="Nome" data-form-v="required|min:3">
    <input name="jform[email]" type="email" data-form-label="E-mail" data-form-v="required|email">
    <button type="submit" :disabled="$form.submitting">Salvar</button>
    <p data-form-status></p>
    <?php echo JHtml::_('form.token'); ?>
</form>
Controller — Joomla 4 e 5
use Joomla\CMS\Factory;
use Joomla\CMS\Language\Text;
use Joomla\CMS\MVC\Controller\BaseController;
use Joomla\CMS\Response\JsonResponse;
use Joomla\CMS\Session\Session;

class ClienteController extends BaseController
{
    public function salvar()
    {
        $app = Factory::getApplication();
        $app->setHeader('Content-Type', 'application/json; charset=utf-8', true);
        $app->sendHeaders();

        if (!Session::checkToken()) {                       // campo oculto do form.token
            echo new JsonResponse(null, Text::_('JINVALID_TOKEN'), true);
            $app->close();
        }

        $dados = $this->input->get('jform', [], 'array');
        $erros = [];
        if (mb_strlen(trim($dados['nome'] ?? '')) < 3) {
            $erros['jform[nome]'] = 'Informe o nome completo.';
        }
        if (!filter_var($dados['email'] ?? '', FILTER_VALIDATE_EMAIL)) {
            $erros['jform[email]'] = 'E-mail inválido.';
        }

        if ($erros) {
            // success:false, message, data.errors → cada erro no seu campo
            echo new JsonResponse(['errors' => $erros], 'Confira os campos destacados.', true);
            $app->close();
        }

        $id = $this->getModel('Cliente')->salvar($dados);
        echo new JsonResponse(['id' => $id], 'Cliente salvo.');
        $app->close();
    }
}
Controller — Joomla 3
class LojaControllerCliente extends JControllerLegacy
{
    public function salvar()
    {
        $app = JFactory::getApplication();
        $app->setHeader('Content-Type', 'application/json; charset=utf-8', true);
        $app->sendHeaders();

        if (!JSession::checkToken()) {
            echo new JResponseJson(null, JText::_('JINVALID_TOKEN'), true);
            $app->close();
        }
        // ... mesma validação ...
        echo new JResponseJson(['id' => $id], 'Cliente salvo.');
        $app->close();
    }
}
  • JsonResponse(dados, mensagem, erro) produz { success, message, messages, data }, exatamente o que data-form-response-adapter="joomla" lê.
  • Mensagens de $app->enqueueMessage('…', 'error') (e warning) entram no resumo de erros.
  • Erros por campo em data.errors, com o nome do HTML (jform[nome]) ou com ponto (jform.nome).
  • O token do Joomla vai no campo oculto gerado por form.token, enviado como qualquer outro campo.

Laravel

Formulário (Blade)
<form x-data x-form action="{{ route('clientes.store') }}" method="post" data-form-response-adapter="laravel" novalidate>
    <input name="nome" data-form-v="required|min:3">
    <input name="email" type="email" data-form-v="required|email"
           data-form-remote="{{ route('clientes.email-disponivel') }}">
    <input name="itens[0][produto]" data-form-label="Produto" data-form-v="required">
    <button type="submit">Salvar</button>
    <p data-form-status></p>
</form>
app/Http/Controllers/ClienteController.php
public function store(Request $request)
{
    // falha → 422 { message, errors: { "email": [...], "itens.0.produto": [...] } } automaticamente
    $dados = $request->validate([
        'nome' => ['required', 'min:3'],
        'email' => ['required', 'email', 'unique:clientes,email'],
        'itens' => ['required', 'array'],
        'itens.*.produto' => ['required', 'string'],
    ]);

    $cliente = Cliente::create($dados);

    return response()->json([
        'success' => true,
        'message' => 'Cliente salvo.',
        'data' => ['id' => $cliente->id],
        'redirect' => route('clientes.show', $cliente),   // com data-form-redirect="response"
    ]);
}

public function emailDisponivel(Request $request)
{
    $existe = Cliente::where('email', $request->input('email'))->exists();
    return response()->json(['valid' => !$existe, 'message' => $existe ? 'E-mail já cadastrado.' : null]);
}
  • O Laravel responde JSON (e não redireciona) porque o AlpineForm envia X-Requested-With: XMLHttpRequest e Accept com JSON.
  • O CSRF segue no cabeçalho X-CSRF-TOKEN a partir de <meta name="csrf-token" content="{{ csrf_token() }}">; token expirado = 419, mostrado como "O token de segurança expirou. Recarregue a página e tente novamente.".
  • Arquivos: $request->file('documentos'); erros como documentos.1 vão para o 2º arquivo.

Recebendo arquivos com segurança

$arquivo = $_FILES['contrato'];
if ($arquivo['error'] !== UPLOAD_ERR_OK) falhaValidacao(['contrato' => 'Envie o contrato.']);

$mime = (new finfo(FILEINFO_MIME_TYPE))->file($arquivo['tmp_name']);   // conteúdo real, não o nome
if ($mime !== 'application/pdf') falhaValidacao(['contrato' => 'O arquivo não é um PDF.']);
if ($arquivo['size'] > 5_000_000) falhaValidacao(['contrato' => 'Máximo 5 MB.']);

$destino = '/dados/privados/' . bin2hex(random_bytes(16)) . '.pdf';   // fora da pasta pública, nome novo
move_uploaded_file($arquivo['tmp_name'], $destino);

Idempotência

Com data-form-idempotency, cada envio traz Idempotency-Key. Guarde a resposta por chave e devolva a mesma se a chave voltar:

$chave = $_SERVER['HTTP_IDEMPOTENCY_KEY'] ?? null;
if ($chave) {
    $salva = $db->fetch('SELECT corpo, status FROM respostas_idempotentes WHERE chave = ? AND usuario = ?', [$chave, $usuarioId]);
    if ($salva) {
        http_response_code((int) $salva['status']);
        header('Content-Type: application/json; charset=utf-8');
        exit($salva['corpo']);                     // mesma resposta, nenhum pedido novo
    }
}

$corpo = json_encode(['success' => true, 'message' => 'Pedido criado.', 'data' => ['id' => criarPedido()]]);
if ($chave) $db->insert('respostas_idempotentes', ['chave' => $chave, 'usuario' => $usuarioId, 'status' => 200, 'corpo' => $corpo]);
header('Content-Type: application/json; charset=utf-8');
echo $corpo;

O backend de referência faz isso com trava e também detecta a mesma chave com dados diferentes (422) ou ainda em processamento (409): server/src/Idempotency.php.

Upload em partes e jobs

Esses protocolos têm mais estado (sessões, partes, fila). Em vez de reescrever do zero, use como modelo o backend de referência deste repositório:

ArquivoO que faz
server/router.phpRoteador para php -S.
server/src/Api.phpTodos os endpoints dos exemplos, com o formato de resposta.
server/src/ChunkStore.phpProtocolo de upload em partes: sessões, partes atômicas, hash, montagem, tokens, limpeza.
server/src/JobQueue.php e server/bin/worker.phpFila e worker de processamento.
server/src/Idempotency.phpIdempotência com trava.
server/src/UploadInspector.phpConferência do conteúdo real dos arquivos.
server/bin/cleanup.phpRemove uploads e tokens expirados (agende no cron).
Rodando o backend de referência
npm run serve                  # http://127.0.0.1:8080/examples/
php server/bin/worker.php      # em outro terminal, para jobs
php server/tests/run.php       # testes do backend
