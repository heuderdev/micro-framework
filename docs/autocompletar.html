Autocompletar

Campo de busca com sugestões da API — cliente, produto, município, CID — acessível por teclado e leitor de tela, que envia o id do item escolhido e pode copiar dados dele para outros campos. Requer alpine-form-autocompletar e o CSS opcional.

Instalação

<link rel="stylesheet" href="/css/alpine-form.css">                        <!-- posição e aparência da lista -->
<script src="/js/alpine-form/alpine-form.min.js"></script>
<script src="/js/alpine-form/alpine-form-autocompletar.min.js"></script>   <!-- depois do núcleo -->
<script defer src="/js/alpine.min.js"></script>
ESM
import autocompletar from 'alpine-form/autocompletar'
AlpineForm.use(autocompletar)

Exemplo executável: examples/autocompletar.php.

Uso

<form x-data x-form action="/api/pedidos" method="post" novalidate>
    <label for="cliente">Cliente</label>
    <div data-form-component="autocompletar" data-form-name="cliente_id" data-form-label="Cliente" data-form-v="required"
         data-form-autocompletar="/api/clientes?busca={termo}"
         data-form-autocompletar-texto="nome"
         data-form-autocompletar-descricao="email">
        <input type="text" id="cliente" placeholder="Digite o nome">
    </div>
    <button type="submit">Criar pedido</button>
</form>
  1. O <div data-form-component="autocompletar"> é o campo: o nome enviado vem de data-form-name, as regras de data-form-v. O <input> de dentro é só para digitar — sem name.
  2. Com 2+ caracteres (data-form-autocompletar-minimo), depois de 250 ms parado, faz GET /api/clientes?busca=ana. Digitou mais: a busca anterior é cancelada; resposta antiga nunca aparece.
  3. Mostra até 10 sugestões (-limite) com o texto e, abaixo, a descrição.
  4. Escolheu: o input mostra o texto e o campo passa a valer o id do item (cliente_id=17).
  5. Digitou de novo depois de escolher: a escolha deixa de valer (valor vazio) — com required, a pessoa não consegue enviar um nome digitado que não corresponde a um cliente.

O que o servidor responde

Lista de itens em qualquer um destes formatos: [...], { "data": [...] } (Laravel, inclusive paginate()), { "success": true, "data": [...] } ou { "itens"|"items"|"results": [...] }. Valor e texto são lidos como nos selects dependentes (id, value…; nome, label…) ou pelos atributos -valor, -texto e -descricao (aceitam caminho com ponto: empresa.nome).

PHP (Helpers PHP)
<?php
require_once __DIR__ . '/../lib/alpine-form.php';
use AlpineForm\Helpers\{Consulta, Resposta};

$c = Consulta::ler($_GET, ['ordenaveis' => ['nome'], 'ordem' => 'nome', 'por_pagina' => 10]);
$busca = $c->like('busca');
$st = $pdo->prepare("SELECT id, nome, email FROM clientes WHERE nome LIKE ? ESCAPE '\\\\' ORDER BY nome LIMIT 10");
$st->execute(["%$busca%"]);
Resposta::enviar([200, ['data' => $st->fetchAll(PDO::FETCH_ASSOC)]]);
Laravel
Route::get('/api/clientes', fn (Request $r) =>
    Cliente::where('nome', 'like', '%' . addcslashes((string) $r->input('busca'), '%_\\') . '%')
        ->orderBy('nome')->limit(10)->get(['id', 'nome', 'email'])
);

Limite o tamanho da resposta no servidor (10–20 itens) e devolva só as colunas exibidas. No salvamento, confira que o id enviado existe e que a pessoa pode usá-lo (ex.: cliente da mesma empresa).

Teclado e acessibilidade

TeclaEfeito
↓ / ↑Marca a próxima/anterior sugestão (circular).
EnterEscolhe a marcada (não envia o formulário). Com a lista fechada, Enter envia normalmente.
EscFecha a lista; com a lista fechada, limpa o campo.
TabFecha a lista e segue para o próximo campo (sem escolher).
  • Padrão WAI-ARIA 1.2: o input recebe role="combobox", aria-autocomplete="list", aria-expanded, aria-controls e aria-activedescendant; a lista é role="listbox" com role="option" e aria-selected.
  • Uma região viva escondida anuncia "Buscando…", "3 resultado(s). Use as setas para escolher.", "Nenhum resultado encontrado." e o item escolhido.
  • Erros de validação (aria-invalid, aria-describedby) são repassados ao input; ao levar a pessoa ao erro, o foco vai para o input.
  • Texto do servidor vira texto (textContent), nunca HTML.

Copiar dados do item escolhido

<div data-form-component="autocompletar" data-form-name="produto_id" data-form-v="required"
     data-form-autocompletar="/api/produtos?busca={termo}" data-form-autocompletar-texto="descricao"
     data-form-autocompletar-campos="preco:preco_unitario, unidade, estoque.disponivel:disponivel">
    <input type="text" aria-label="Produto">
</div>
<input name="preco_unitario" data-form-mask="currency">
<input name="unidade">
<input name="disponivel" readonly>

Mesma regra do autopreenchimento: só preenche campos vazios ou que ainda têm o valor que ele colocou — o que a pessoa digitou fica. Para reagir de outro jeito, use o evento:

<form x-data="{ limite: null }" x-form @form:autocompletar-selecionado="limite = $event.detail.item && $event.detail.item.limite_credito" novalidate>
    <div data-form-component="autocompletar" data-form-name="cliente_id" data-form-autocompletar="/api/clientes?busca={termo}"><input type="text" aria-label="Cliente"></div>
    <p x-show="limite">Limite de crédito: <span x-text="limite"></span></p>
</form>

Edição, reset e texto livre

Edição: valor salvo + texto
<div data-form-component="autocompletar" data-form-name="cliente_id" data-form-autocompletar="/api/clientes?busca={termo}"
     data-form-autocompletar-inicial="17">
    <input type="text" value="Ana Almeida" aria-label="Cliente">
</div>

$form.reset() (ou o reset do formulário) volta ao valor inicial e ao texto do value.

Texto livre (sugestões, mas aceita qualquer valor)
<div data-form-component="autocompletar" data-form-name="cidade" data-form-autocompletar="/api/cidades?busca={termo}" data-form-autocompletar-livre>
    <input type="text" aria-label="Cidade">
</div>

Com -livre, o valor é o texto digitado; escolher uma sugestão usa o valor dela.

Referência

Atributo (no elemento com data-form-component="autocompletar")PadrãoEfeito
data-form-autocompletarobrigatórioURL da mesma origem com {termo}.
data-form-autocompletar-valor · -texto · -descricaoautomático · automático · —Campos do item (aceitam caminho com ponto).
data-form-autocompletar-minimo2Caracteres para buscar (0 a 50).
data-form-autocompletar-debounce250msEspera depois da digitação.
data-form-autocompletar-limite10Máximo de sugestões exibidas (1 a 100).
data-form-autocompletar-campos—chave:campo copiados ao escolher.
data-form-autocompletar-inicial—Valor salvo (edição); o texto vem do value do input.
data-form-autocompletar-livrefalseAceita o texto digitado como valor.
data-form-autocompletar-vazio"Nenhum resultado encontrado."Texto quando a busca não traz nada.

Eventos (no elemento, sobem até o form): form:autocompletar-selecionado ({ name, valor, texto, item }) e form:autocompletar-erro ({ name, status }). API: AlpineForm.autocompletar.limparCache(). Mensagens: autocompletar.carregando, .resultados, .vazio, .erro, .escolhido em AlpineForm.messages. Classes: af-autocompletar-lista, -opcao, -ativo, -texto, -descricao, -vazio.

Erros de configuração (sem {termo}, outra origem, input com name, sem input, número inválido) bloqueiam o envio e aparecem no console.
