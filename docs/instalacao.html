Instalação

Quais arquivos copiar, em que ordem carregar e como fazer isso numa página HTML, no Joomla, no Laravel e com bundler (Vite).

Arquivos

Gere os arquivos com npm install e npm run build (ou use os que já estão em dist/) e copie para a pasta pública do seu projeto só o que for usar:

ArquivoQuando carregar
dist/alpine-form.min.jsSempre. Núcleo.
dist/alpine-form-masks.min.jsSe usar data-form-mask.
dist/alpine-form-chunks.min.jsSe usar data-form-chunked (upload em partes).
dist/alpine-form-inspectors.min.jsSe usar as regras csv, csv_headers, json, pdf_signature, xlsx_signature, media_duration_*.
dist/alpine-form-rascunho.min.jsSe usar data-form-rascunho (rascunho automático).
dist/alpine-form-bootstrap.min.jsSe a página usa Bootstrap 5 e você quer data-form-ui="bootstrap".
css/alpine-form.cssOpcional: estilo mínimo para erros, resumo, lista de arquivos e barra de progresso (dispensável com Bootstrap).
Alpine.js 3Sempre. Não vem junto: use node_modules/alpinejs/dist/cdn.min.js ou a cópia que seu projeto já tem.

Cada módulo existe em três versões: .min.js (produção), .js (mesmo código legível, para depurar) e .esm.js (para import).

Ordem de carregamento

  1. alpine-form.min.js — define window.AlpineForm e espera o Alpine iniciar.
  2. Módulos opcionais — se registram em window.AlpineForm.
  3. Suas extensões e AlpineForm.configure(), se houver.
  4. Alpine.js com defer — sempre por último.
HTML puro
<head>
    <meta name="csrf-token" content="TOKEN_GERADO_PELO_SERVIDOR">   <!-- opcional: ver abaixo -->
    <link rel="stylesheet" href="/js/alpine-form/alpine-form.css">

    <script src="/js/alpine-form/alpine-form.min.js"></script>
    <script src="/js/alpine-form/alpine-form-masks.min.js"></script>
    <script>
        AlpineForm.configure({ debounce: 300 })   // opcional
    </script>
    <script defer src="/js/alpine.min.js"></script>
</head>
Alpine antes do AlpineForm

Se o Alpine iniciar antes do núcleo carregar, os formulários já processados não são inicializados e o console avisa "O Alpine parece já ter sido iniciado; carregue alpine-form antes do Alpine". Ponha o Alpine por último e com defer.

Token CSRF

Duas formas, use a que o seu backend espera:

  • Meta tag + cabeçalho: com <meta name="csrf-token" content="…"> na página, todo envio para a mesma origem leva o cabeçalho X-CSRF-TOKEN. É o padrão do Laravel.
  • Campo oculto: qualquer <input type="hidden"> dentro do form é enviado normalmente. É o padrão do Joomla (HTMLHelper::_('form.token')).
Outro nome de meta ou de cabeçalho
AlpineForm.configure({ csrf: { meta: 'xsrf', header: 'X-XSRF-TOKEN' } })
AlpineForm.configure({ csrf: null })   // desliga o envio automático do cabeçalho

Joomla 3, 4 e 5

Copie os arquivos para media/com_seucomponente/js/ e carregue na view, nesta ordem:

tmpl/default.php
use Joomla\CMS\HTML\HTMLHelper;   // Joomla 3: use JHtml no lugar de HTMLHelper

HTMLHelper::_('stylesheet', 'com_loja/alpine-form.css', ['version' => 'auto', 'relative' => true]);
HTMLHelper::_('script', 'com_loja/alpine-form.min.js', ['version' => 'auto', 'relative' => true]);
HTMLHelper::_('script', 'com_loja/alpine-form-masks.min.js', ['version' => 'auto', 'relative' => true]);
HTMLHelper::_('script', 'com_loja/alpine.min.js', ['version' => 'auto', 'relative' => true], ['defer' => true]);

Com 'relative' => true, o Joomla procura com_loja/alpine-form.min.js em media/com_loja/js/ (e o CSS em media/com_loja/css/).

Formulário com token do Joomla
<form x-data x-form action="<?php echo JRoute::_('index.php?option=com_loja&task=cliente.salvar&format=json'); ?>"
      method="post" data-form-response-adapter="joomla" novalidate>
    <input name="jform[nome]" data-form-v="required|min:3" data-form-label="Nome">
    <button type="submit">Salvar</button>
    <p data-form-status></p>
    <?php echo HTMLHelper::_('form.token'); ?>
</form>

Confira no código-fonte da página gerada se o alpine.min.js ficou depois dos outros scripts. Se o template já carrega o Alpine, não carregue de novo: apenas garanta que alpine-form.min.js venha antes dele. O controller está em Backend › Joomla.

Laravel

resources/views/layouts/app.blade.php
<meta name="csrf-token" content="{{ csrf_token() }}">
<link rel="stylesheet" href="{{ asset('js/alpine-form/alpine-form.css') }}">
<script src="{{ asset('js/alpine-form/alpine-form.min.js') }}"></script>
<script src="{{ asset('js/alpine-form/alpine-form-masks.min.js') }}"></script>
<script defer src="{{ asset('js/alpine.min.js') }}"></script>

Com a meta tag, o cabeçalho X-CSRF-TOKEN segue automaticamente. Use data-form-response-adapter="laravel" para ler o 422 de validação (exemplo de controller).

Vite / bundler (ESM)

main.js
import Alpine from 'alpinejs'
import AlpineFormPlugin, { AlpineForm } from 'alpine-form'
import masks from 'alpine-form/masks'
import chunks from 'alpine-form/chunks'
import inspectors from 'alpine-form/inspectors'
import bootstrap from 'alpine-form/bootstrap'
import rascunho from 'alpine-form/rascunho'
import 'alpine-form/css'

AlpineForm.use(masks).use(chunks).use(inspectors).use(bootstrap).use(rascunho)
AlpineForm.configure({ validation: 'live' })

Alpine.plugin(AlpineFormPlugin)
window.Alpine = Alpine
window.AlpineForm = AlpineForm   // opcional: acesso pelo console
Alpine.start()

Sem bundler, o mesmo funciona com <script type="module"> apontando para os .esm.js (veja examples/esm-boot.js).

Conferindo se funcionou

Abra o console do navegador na página:

Console
AlpineForm.version              // "1.0.0"
AlpineForm.diagnose()           // [] = todos os <form x-form> foram inicializados
AlpineForm.get('meuForm')       // estado do formulário com id="meuForm" (ou null)
AlpineForm.registry.names('mask')   // máscaras disponíveis (vazio se o módulo não carregou)

Se diagnose() listar formulários, falta x-data no form (ou num elemento acima dele), ou ele está dentro de x-ignore. Veja Erros e soluções.
