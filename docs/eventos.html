Eventos e hooks

Reagir a cada momento do formulário com eventos DOM (@form:success no Alpine) ou com hooks de configuração que podem alterar ou impedir o envio.

Como escutar

Os eventos são disparados no <form> e sobem (bubbling). Os dados ficam em event.detail.

Com Alpine
<form x-data x-form action="/api/cadastro" method="post"
      @form:success="$dispatch('notificar', { texto: $event.detail.result.message })"
      @form:error="console.warn($event.detail.error.kind, $event.detail.error.message)" novalidate>
Com JavaScript
document.getElementById('cadastro').addEventListener('form:success', event => {
    console.log('Salvo:', event.detail.result.data)
})

// todos os formulários da página
document.addEventListener('form:error', event => {
    meuMonitoramento.registrar(event.target.id, event.detail.error)
})

Exemplos

Confirmar antes de enviar
<form x-data x-form action="/api/excluir" method="post"
      @form:before-submit="confirm('Tem certeza?') || $event.preventDefault()" novalidate>
Avisar ao sair com alterações não salvas
<form x-data x-form action="/api/perfil" method="post"
      x-init="window.addEventListener('beforeunload', e => { if ($form.dirty && !$form.success) e.preventDefault() })" novalidate>
Fechar o modal no sucesso
<div x-data="{ aberto: true }" x-show="aberto">
    <form x-data x-form action="/api/contato" method="post" @form:success="aberto = false" novalidate>
        ...
    </form>
</div>
Auto-salvar rascunho a cada mudança (com espera)
<form x-data="{ timer: null }" x-form action="/api/rascunho" method="post"
      @form:change="clearTimeout(timer); timer = setTimeout(() => $form.submit(), 1500)" novalidate>
Analytics
<form x-data x-form action="/api/lead" method="post"
      @form:invalid="gtag('event', 'form_invalido', { campos: Object.keys($event.detail.errors).join(',') })"
      @form:success="gtag('event', 'lead_enviado')" novalidate>

Hooks de configuração

Funções em hooks (no AlpineForm.configure ou no objeto de x-form). Podem ser async: o envio espera.

HookRecebeUso
beforeSubmit(state, { submitter })estado do formDevolver false cancela o envio.
beforeRequest(request, state){ url, method, headers, body, … }Alterar cabeçalhos/URL antes de enviar.
afterResponse(result, state)resposta já interpretadaLog, métricas, ajustes.
reveal(campo, estadoDoCampo)elemento a focarAbrir aba/accordion/modal antes do foco.
AlpineForm.configure({
    hooks: {
        async beforeSubmit(state) {
            // getValue devolve o canônico ("12000.00" mesmo com máscara de moeda)
            if (state.has('valor') && Number(state.getValue('valor')) > 10000) {
                return confirm('Valor acima de R$ 10.000. Continuar?')
            }
        },
        beforeRequest(request) {
            request.headers['X-Tela'] = location.pathname
        },
        afterResponse(result) {
            if (result.kind === 'auth') location.href = '/login'
        },
    },
})

Abrir accordion antes do foco

<form x-data x-form="{ hooks: { reveal: el => el.closest('details')?.setAttribute('open', '') } }"
      action="/api/cadastro" method="post" novalidate>
    <details>
        <summary>Dados adicionais</summary>
        <input name="rg" data-form-v="required">
    </details>
    <button type="submit">Salvar</button>
</form>
