Máscaras

Formatação durante a digitação com cursor preservado, colagem, seleção e IME, separando o valor exibido do valor validado e do enviado. Requer alpine-form-masks.

Máscara não é validação

529.982.247-24 está bem formatado e é um CPF inválido. Use sempre a máscara junto com a regra: data-form-mask="cpf" data-form-v="required|cpf".

Máscaras só em input type="text", tel, search ou textarea. O inputmode adequado (teclado numérico no celular) é adicionado se você não declarou um.

Escolhendo o que validar e o que enviar

RepresentaçãoO que é
rawSó os caracteres significativos, sem pontuação. Na moeda, sinal + dígitos digitados (não é um número).
formattedComo aparece no campo.
canonicalForma para máquinas: documentos sem pontuação, datas ISO, números com ponto e casas fixas (texto, nunca Number).
<!-- enviar CPF sem pontuação -->
<input name="cpf" data-form-mask="cpf" data-form-v="required|cpf" data-form-submit-value="raw">

<!-- validar e enviar o CEP formatado -->
<input name="cep" data-form-mask="cep" data-form-v="required|pattern" data-form-pattern="^\d{5}-\d{3}$"
       data-form-mask-validation-value="formatted">

Nunca há um input hidden duplicado: o valor enviado é calculado no momento do envio. Para ler pelo código: $form.getValue('cpf', { as: 'raw' }).

CPF, CNPJ e CPF/CNPJ

<input name="cpf" data-form-mask="cpf" data-form-v="required|cpf" data-form-submit-value="raw">
<input name="cnpj" data-form-mask="cnpj" data-form-v="required|cnpj" data-form-submit-value="raw">
<input name="documento" data-form-mask="cpf_cnpj" data-form-v="required|cpf_cnpj" data-form-submit-value="raw">

cnpj aceita letras nas 12 primeiras posições (CNPJ alfanumérico), convertidas para maiúsculas. cpf_cnpj troca o formato sozinho: até 11 dígitos sem letra → CPF; mais que isso ou com letra → CNPJ.

Telefone e CEP

<input name="telefone" type="tel" data-form-mask="telefone_br" data-form-v="required|telefone" data-form-submit-value="raw">
<input name="whatsapp" type="tel" data-form-mask="celular" data-form-v="required|telefone:celular">
<input name="fixo" type="tel" data-form-mask="telefone_fixo" data-form-v="telefone:fixo">
<input name="cep" data-form-mask="cep" data-form-mask-placeholder="_" data-form-v="required|cep">

Colar (11) 98765-4321 ou 11987654321 dá o mesmo resultado. data-form-mask-placeholder="_" mostra _____-___ como placeholder (se o input não tiver um).

Como a pessoa digita: livremente, com vírgula para os centavos — 1234,5 mostra R$ 1.234,5 e, ao sair, R$ 1.234,50. Zeros à esquerda somem (0071 → R$ 71). Ao colar 1234.56, o ponto é entendido como decimal; 1.234 (três dígitos após o ponto) como milhar.

Data, hora e mês

<input name="nascimento" data-form-mask="date" data-form-v="required|date|before:today">
<input name="horario" data-form-mask="time" data-form-v="required|date:time">
<input name="competencia" data-form-mask="month_year" data-form-v="required|date:month">

A pessoa vê 31/12/2026; validação e envio usam 2026-12-31. Uma data inexistente (31/02/2026) não ganha forma ISO e a regra date a recusa.

Cartão

<input name="cartao" data-form-mask="card" data-form-mask-card-brands="visa,mastercard,elo,amex"
       data-form-v="required|card:visa,mastercard,elo,amex" autocomplete="cc-number">

O agrupamento e o tamanho máximo seguem a bandeira detectada (Amex: 4-6-5). Validação e envio usam só os dígitos.

Padrão personalizado

<input name="codigo" data-form-mask="pattern" data-form-mask-pattern="AAA-9999" data-form-mask-case="upper"
       data-form-v="required|pattern" data-form-pattern="^[A-Z]{3}-[0-9]{4}$">

<input name="placa" data-form-mask="pattern" data-form-mask-pattern="AAA-9*99" data-form-mask-case="upper">
<input name="protocolo" data-form-mask="pattern" data-form-mask-pattern="\P\R\O-99999">
<input name="pis" data-form-mask="pattern" data-form-mask-pattern="999.99999.99-9" data-form-submit-value="raw">
TokenAceita

data-form-mask-case: upper ou lower. No padrão personalizado, validação e envio usam o valor formatado por padrão.

Valores iniciais, API e reset

<!-- valor vindo do servidor: formatado ao carregar, sem marcar o formulário como alterado -->
<input name="cep" value="01310100" data-form-mask="cep">
<input name="valor" data-form-mask="currency">
<input name="cpf" data-form-mask="cpf">

<button type="button" @click="$form.setValue('valor', '1234.5', { as: 'canonical' })">Preencher R$ 1.234,50</button>
<button type="button" @click="$form.setValue('cpf', '52998224725')">Preencher CPF</button>
<span x-text="$form.ready ? $form.getValue('valor', { as: 'canonical' }) : ''"></span>

setValue aceita as: 'display' (padrão), 'raw', 'formatted' ou 'canonical'; getValue aceita esses e mais 'validation' e 'submit'. O reset do formulário restaura o valor original e reaplica a formatação.

Cursor, colagem e edição

  • Digitar no meio mantém o cursor logo após o caractere digitado.
  • Backspace logo depois de um separador apaga o dígito anterior (não fica "preso" no ponto).
  • Selecionar um trecho e digitar substitui o trecho.
  • Colar texto formatado ou só números produz o mesmo valor.
  • Teclados de composição (IME) só são formatados ao terminar a composição.
  • A máscara pode ser trocada dinamicamente (:data-form-mask="tipo === 'pj' ? 'cnpj' : 'cpf'"): o valor é reformatado a partir dos caracteres significativos.

Desfazer (Ctrl+Z) usa o histórico do navegador e pode pular estados intermediários, porque o valor é reescrito pela máscara.
