Tipos de campo

Como cada tipo de controle é lido, validado e enviado: texto, número, select, radio, checkbox, datas, hidden, senha, desabilitado e componentes próprios.

Texto, textarea, e-mail, URL

<input name="nome" data-form-v="required|min:3">
<input name="email" type="email" data-form-v="required|email">
<input name="site" type="url" data-form-v="url">
<textarea name="descricao" data-form-v="max:2000"></textarea>

O valor é o texto. Espaços nas pontas contam (use data-form-normalize="trim" para removê-los no valor validado e enviado, sem alterar o que aparece).

Número

<input name="idade" type="number" min="0" data-form-v="required|integer|min:18">

Em type="number", min/max comparam o valor. Se o navegador não consegue ler o número digitado, o erro é "Informe um número válido em :field.". Para valores monetários com vírgula, prefira type="text" com máscara currency ou decimal (máscara em type="number" não é permitida).

Select

<select name="estado" data-form-v="required">
    <option value="">Selecione</option>
    <option value="SP">São Paulo</option>
    <option value="MG">Minas Gerais</option>
</select>

A opção de valor vazio conta como "não preenchido". Valida ao mudar a seleção. Opções disabled são ignoradas.

Select múltiplo

<select name="estados[]" multiple data-form-v="required|min:2|max:3">
    <option value="SP">São Paulo</option>
    <option value="RJ">Rio de Janeiro</option>
    <option value="MG">Minas Gerais</option>
</select>

O valor é uma lista; min/max contam opções selecionadas. No envio, cada opção vira uma entrada estados[].

Radio

<fieldset>
    <legend>Plano</legend>
    <label><input type="radio" name="plano" value="basico" data-form-v="required"
                  data-form-msg.required="Escolha um plano."> Básico</label>
    <label><input type="radio" name="plano" value="pro"> Pro</label>
</fieldset>

Todos os radios de mesmo nome formam um campo. Declare as regras em um deles (ou repita exatamente iguais — valores diferentes no mesmo grupo são erro). O erro aparece no fim do <fieldset>.

Checkbox individual

<label><input type="checkbox" name="termos" value="1" data-form-v="accepted"> Aceito os termos</label>

<label><input type="checkbox" name="newsletter" value="1" data-form-unchecked-value="0"> Receber novidades</label>

Desmarcado, um checkbox não é enviado (comportamento do HTML). Com data-form-unchecked-value, o valor indicado é enviado quando desmarcado — útil para o servidor gravar "0".

Grupo de checkboxes

<fieldset>
    <legend>Interesses</legend>
    <label><input type="checkbox" name="interesses[]" value="php" data-form-v="required|min:2"> PHP</label>
    <label><input type="checkbox" name="interesses[]" value="js"> JavaScript</label>
    <label><input type="checkbox" name="interesses[]" value="dados"> Dados</label>
</fieldset>

Vários checkboxes com o mesmo nome (ou um nome terminado em []) formam um grupo cujo valor é a lista dos marcados.

Datas e horas

<input name="nascimento" type="date" data-form-v="required|before:today">
<input name="inicio" type="datetime-local" data-form-v="required|after:now">
<input name="horario" type="time" data-form-v="required">
<input name="competencia" type="month" data-form-v="required">

<!-- texto com data brasileira, sem máscara -->
<input name="emissao" data-form-date-format="br" data-form-v="required|date|before_or_equal:today">

<!-- texto com tipo explícito -->
<input name="hora_texto" data-form-date-kind="time" data-form-v="date">

Os tipos nativos usam o formato ISO que o navegador entrega. Em campos de texto, o formato é ISO, a menos que data-form-date-format="br" (no campo, grupo ou form) ou uma máscara de data esteja presente.

Hidden

<input type="hidden" name="id" value="42">
<input type="hidden" name="token_pagamento" data-form-v="required"
       data-form-msg.required="Clique em “Gerar pagamento” antes de enviar.">

Hidden sem data-form-v é apenas enviado. Com regras, é validado, e como não tem onde mostrar o erro, a mensagem vai para o resumo (ou para data-form-error-target).

Senha e dados sensíveis

<input name="senha" type="password" data-form-v="required|min:8">
<input name="cartao_cvv" data-form-sensitive data-form-v="required|digits:3">

Campos type="password" e com data-form-sensitive nunca expõem o valor: $form.fields.senha.value é null, o evento form:change não traz o valor, :value nas mensagens fica vazio, normalizadores são proibidos e validação remota por GET exige autorização explícita.

Desabilitado, somente leitura e ignorado

disabled (ou dentro de <fieldset disabled>)NãoNão

data-form-ignoreNãoSim, se tiver name (serialização normal do HTML)
Sem nameNãoNão (com data-form-v vira erro de configuração)
Oculto (x-show) com data-form-hidden="skip"Não, enquanto invisívelSim
Desabilitar com Alpine
<div x-data="{ entrega: false }">
    <label><input type="checkbox" x-model="entrega"> Entregar</label>
    <input name="endereco" :disabled="!entrega" data-form-v="required">
</div>

Botões de envio

<button type="submit" name="acao" value="rascunho" formnovalidate>Salvar rascunho</button>
<button type="submit" name="acao" value="publicar">Publicar</button>
<button type="submit" formaction="/api/preview" formmethod="post">Pré-visualizar</button>

O botão clicado é enviado com seu name/value. formnovalidate pula a validação no cliente; formaction, formmethod e formenctype mudam o destino só para aquele botão.

Campos fora do <form>

<form id="pedido" x-data x-form action="/pedido" method="post" novalidate>...</form>

<aside>
    <input name="cupom" form="pedido" data-form-v="alphanumeric|length:8">
</aside>

Controles com o atributo HTML form="id" participam da validação e do envio. Ver também data-form-for para exibir estado fora do form.

Componentes próprios

Um seletor de estrelas, um editor rico, um select customizado: registre um adaptador com getValue, setValue e subscribe e use data-form-component + data-form-name.

<script>
AlpineForm.component('estrelas', {
    getValue: el => el.getAttribute('data-valor') || '',
    setValue(el, value) {
        el.setAttribute('data-valor', value == null ? '' : String(value))
    },
    subscribe(el, notify) {
        const onClick = event => {
            const botao = event.target.closest('button[value]')
            if (!botao) return
            el.setAttribute('data-valor', botao.value)
            notify()
        }
        el.addEventListener('click', onClick)
        return () => el.removeEventListener('click', onClick)
    },
})
</script>

<div data-form-component="estrelas" data-form-name="nota" data-form-label="Avaliação"
     data-form-v="required|min_value:3" role="group" aria-label="Avaliação">
    <button type="button" value="1">★</button>
    <button type="button" value="2">★★</button>
    <button type="button" value="3">★★★</button>
    <button type="button" value="4">★★★★</button>
    <button type="button" value="5">★★★★★</button>
</div>

O valor entra na validação e no envio com o nome nota. Com data-form-disabled no elemento, o componente fica fora da validação e do envio.
