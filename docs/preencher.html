Autopreenchimento

Quando um campo fica completo e válido — CEP, CNPJ, matrícula, código do produto — busca os dados na API e preenche os outros campos, sem apagar o que a pessoa digitou. Requer alpine-form-preencher.

Instalação

<script src="/js/alpine-form/alpine-form.min.js"></script>
<script src="/js/alpine-form/alpine-form-masks.min.js"></script>      <!-- para a máscara do CEP/CNPJ -->
<script src="/js/alpine-form/alpine-form-preencher.min.js"></script>  <!-- depois do núcleo -->
<script defer src="/js/alpine.min.js"></script>
ESM
import preencher from 'alpine-form/preencher'
AlpineForm.use(preencher)

Exemplo executável: examples/preencher.php.

CEP → endereço

<form x-data x-form action="/api/clientes" method="post" novalidate>
    <input name="cep" data-form-mask="cep" data-form-v="required|cep"
           data-form-preencher="/api/cep/{cep}"
           data-form-preencher-minimo="8"
           data-form-preencher-campos="logradouro, bairro, localidade:cidade, uf">
    <input name="logradouro" data-form-v="required">
    <input name="numero" data-form-v="required">
    <input name="bairro">
    <input name="cidade">
    <input name="uf">
    <button type="submit">Salvar</button>
</form>
  1. A pessoa digita o CEP. Com 8 dígitos (data-form-preencher-minimo, contado no valor bruto: sem traço), o módulo espera a digitação parar (400 ms) e valida o próprio campo. CEP inválido não gera requisição.
  2. Faz GET /api/cep/01001000 ({cep} = valor bruto do campo, codificado).
  3. Da resposta, copia logradouro → logradouro, bairro → bairro, localidade → cidade, uf → uf.
  4. Digitou outro CEP no meio da busca: a anterior é cancelada; resposta antiga nunca é aplicada.

Mapeando os campos

Em data-form-preencher-camposSignifica
bairroChave bairro da resposta → campo bairro.
localidade:cidadeChave localidade → campo cidade.
endereco.cep:cepChave aninhada ({ "endereco": { "cep": "…" } }).
uf:endereco[uf]Campo com nome de colchetes (ou endereco.uf).

A resposta pode ser o objeto direto, { "success": true, "data": { … } } (contrato AlpineForm / Joomla) ou { "data": { … } } (Laravel Resource). Valores que não são texto/número (objetos, listas, null) são ignorados.

O que a pessoa digitou é preservado

  • Só preenche campo vazio ou que ainda tem o valor que o próprio módulo colocou. Se a pessoa escreveu o bairro e depois digitou o CEP, o bairro fica.
  • Trocou o CEP: os campos que vieram do CEP anterior são atualizados; os digitados, não.
  • Para sempre substituir: data-form-preencher-sobrescrever.
  • Nunca preenche senha, campo data-form-sensitive, arquivo ou campo desabilitado.
  • Campos já validados são revalidados com o valor novo (erros somem quando o preenchimento os resolve).

Não encontrado e falhas

<input name="cep" data-form-mask="cep" data-form-v="cep"
       data-form-preencher="/api/cep/{cep}" data-form-preencher-minimo="8"
       data-form-preencher-campos="logradouro, bairro, cidade, uf"
       data-form-preencher-nao-encontrado="CEP não encontrado. Preencha o endereço manualmente.">
  • Não encontrado — HTTP 404/400/422, success: false ou { "erro": true }: a mensagem aparece no próprio campo (como erro do servidor, some quando o valor muda) e nada é apagado. Evento form:preencher-erro com motivo: 'nao-encontrado'.
  • Falha — rede, 5xx, resposta que não é JSON: nada muda no formulário (a pessoa preenche à mão), o erro vai ao console e o evento traz motivo: 'falha'. Tentar de novo com o mesmo valor é permitido.
  • O campo de origem recebe data-form-preencher-estado (carregando, pronto, nao-encontrado, erro) e aria-busy durante a busca:
input[data-form-preencher-estado="carregando"] {
    background: url(/img/spinner.svg) no-repeat right .5rem center / 1rem;
}

Com selects dependentes (UF e cidade)

<input name="cep" data-form-mask="cep" data-form-v="cep" data-form-preencher="/api/cep/{cep}" data-form-preencher-minimo="8"
       data-form-preencher-campos="logradouro, uf, ibge:cidade">
<input name="logradouro">
<select name="uf" data-form-opcoes="/api/ufs"><option value="">UF</option></select>
<select name="cidade" data-form-opcoes="/api/cidades?uf={uf}"><option value="">Cidade</option></select>

Com o módulo alpine-form-opcoes carregado, o módulo escolhe a UF, a lista de cidades carrega e a cidade é selecionada quando a lista chega. Liste a dependência (uf) antes do campo que depende dela (ibge:cidade). Use um código estável (IBGE, id) como valor das cidades — o nome pode vir com grafia diferente.

CNPJ → empresa e outros casos

<input name="cnpj" data-form-mask="cnpj" data-form-v="required|cnpj"
       data-form-preencher="/api/empresas/{cnpj}" data-form-preencher-minimo="14"
       data-form-preencher-campos="razao_social, nome_fantasia, endereco.cep:cep, endereco.numero:numero">

<input name="matricula" data-form-preencher="/api/funcionarios/{matricula}" data-form-preencher-minimo="6"
       data-form-preencher-campos="nome, setor, ramal">

<input name="sku" data-form-preencher="/api/produtos/{sku}?tabela={tabela}" data-form-preencher-minimo="5"
       data-form-preencher-campos="descricao, preco:preco_unitario">
<select name="tabela"><option value="varejo">Varejo</option><option value="atacado">Atacado</option></select>

A URL pode citar outros campos ({tabela}). A busca dispara quando o campo com data-form-preencher muda; para buscar também quando outro campo mudar, chame AlpineForm.preencher.buscar(form, 'sku') (ex.: @change no select).

Serviços prontos e outras origens

<input name="cep" data-form-mask="cep" data-form-preencher="viacep"
       data-form-preencher-campos="logradouro, bairro, localidade:cidade, uf">

<input name="cnpj" data-form-mask="cnpj" data-form-preencher="brasilapi-cnpj"
       data-form-preencher-campos="razao_social, nome_fantasia, cep, logradouro, numero, municipio:cidade, uf">
ServiçoURLMínimo
viacephttps://viacep.com.br/ws/{cep}/json/ ({"erro": true} = não encontrado)8
brasilapi-cephttps://brasilapi.com.br/api/cep/v1/{cep}8
brasilapi-cnpjhttps://brasilapi.com.br/api/cnpj/v1/{cnpj}14
Seu próprio serviço / outra origem
AlpineForm.preencher.servico('cep-interno', {
    url: '/api/v2/enderecos/cep/{campo}',          // {campo} = valor do próprio campo
    minimo: 8,
    naoEncontrado: json => json.status === 'NAO_ENCONTRADO',
})
AlpineForm.preencher.permitirOrigem('https://api.parceiro.com.br')   // libera URL de outra origem

Para outras origens o módulo não envia cookies nem cabeçalhos próprios, mas o valor (CEP, CNPJ) sai para o serviço externo, e a disponibilidade dele passa a afetar o seu formulário. Em ambiente regulado, consulte por um endpoint do próprio sistema (que pode usar cache e registrar a consulta). URLs de outra origem sem permitirOrigem são erro de configuração.

O endpoint no servidor

PHP (Helpers PHP)
<?php
require_once __DIR__ . '/../lib/alpine-form.php';
use AlpineForm\Helpers\Resposta;

$cep = preg_replace('/\D+/', '', $_GET['cep'] ?? '');
if (strlen($cep) !== 8) {
    Resposta::enviar(Resposta::erro('CEP inválido.', 422));
}
$endereco = buscarEnderecoNoCache($cep) ?? consultarServicoDeCep($cep);   // seu cache + provedor
if (!$endereco) {
    Resposta::enviar(Resposta::erro('CEP não encontrado.', 404));
}
Resposta::enviar(Resposta::sucesso($endereco));   // { success: true, data: { logradouro, bairro, ... } }

Referência

Atributo (no campo de origem)PadrãoEfeito
data-form-preencherobrigatórioURL com {campo} ou serviço (viacep, brasilapi-cep, brasilapi-cnpj, registrados).
data-form-preencher-camposobrigatóriochave:campo separados por vírgula.
data-form-preencher-minimo1 (serviços: 8 ou 14)Caracteres do valor bruto para buscar.
data-form-preencher-debounce400msEspera depois da digitação.
data-form-preencher-sobrescreverfalseSubstitui também o que a pessoa digitou.
data-form-preencher-nao-encontradomensagem padrãoErro mostrado no campo quando não há dados.

Global: AlpineForm.preencher.buscar(formOuId, nome) (Promise com true quando preencheu), servico(nome, { url, minimo, naoEncontrado }), permitirOrigem(origem). Eventos no form: form:preenchido ({ name, campos }) e form:preencher-erro ({ name, status, motivo }). Mensagem padrão: AlpineForm.messages['preencher.nao_encontrado'].
