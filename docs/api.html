API $form

Todas as propriedades e métodos do estado de um formulário, acessível como $form no HTML e por AlpineForm.get() no JavaScript, além da API global AlpineForm.

Como acessar

No HTML (dentro do form ou de um data-form-for)
<button :disabled="$form.submitting" @click="$form.reset()">Limpar</button>
No JavaScript
const form = AlpineForm.get('cadastro')            // pelo id
const mesmo = AlpineForm.get(document.querySelector('#cadastro'))
Em expressões do HTML, espere o ready

Os campos são descobertos logo depois que o Alpine processa o formulário. Uma expressão como x-text="$form.getValue('valor')" roda antes disso e lançaria "Campo não encontrado". Proteja com $form.ready ou $form.has('valor'): x-text="$form.ready ? $form.getValue('valor') : ''". hasError, firstError, field e has já são seguros.

Nomes de campo aceitam a forma do HTML (itens[0][nome]) ou a chave (itens.0.nome). Nome inexistente lança erro, exceto em field, has, hasError e firstError.

Métodos

validate()

validate(): Promise<{ valid, errors, invalidFields }>

Valida todos os campos e mostra os erros. Não envia, não foca, não mostra resumo.

const { valid, invalidFields } = await form.validate()

validateField(nome)

validateField(nome): Promise<{ valid, errors }>

Valida um campo agora (marca como tocado; validação remota sem espera).

submit({ submitter })

submit(opções?): Promise<{ ok, result?, reason?, error? }>

Fluxo completo de envio. Durante um envio, devolve a mesma Promise (sem requisição duplicada). reason: invalid, canceled, prevented ou o tipo do erro.

const r = await form.submit({ submitter: document.querySelector('[value=publicar]') })
if (r.ok) console.log(r.result.data)

cancel()

cancel(): boolean

Cancela validação/envio em andamento; em processamento, para de acompanhar. Devolve se havia algo a cancelar.

reset() · resetValidation()

reset(): volta os valores ao original do HTML, limpa arquivos, erros e resultado (dispara form:reset, cancelável). resetValidation(): só limpa erros e o estado "tocado", mantendo os valores.

setValue(nome, valor, opções)

setValue(nome, valor, { as = 'display', touch = false, validate, silent = false }): valorExibido

Define o valor de qualquer tipo de campo (texto, select, select múltiplo com lista, radio, checkbox, componente). as: display, raw, formatted, canonical (com máscara). Revalida se o campo já estava validado ou com validate: true. silent não dispara form:change.

form.setValue('estado', 'SP')
form.setValue('interesses[]', ['php', 'js'])
form.setValue('termos', true)
form.setValue('valor', '1234.5', { as: 'canonical' })
form.setValue('cep', '01310100', { touch: true, validate: true })

getValue(nome, { as }) · getValues(opções)

getValue(nome, { as = 'canonical' }) · getValues({ as = 'submit', format = 'object' | 'entries', submitter })

as: display, raw, formatted, canonical, validation, submit. getValues({ format: 'entries' }) devolve exatamente os pares que seriam enviados.

form.getValue('cpf', { as: 'raw' })           // "52998224725"
form.getValues()                               // { nome: "Ana", cpf: "529.982.247-25", ... }
form.getValues({ format: 'entries' })          // [["nome","Ana"], ["cpf","52998224725"], ...]

setErrors(erros, opções) · clearErrors(nome?)

setErrors({ campo: msg | [msgs] } | [msgsGerais], { general = [], replace = true })

Mostra erros como se viessem do servidor. Com replace: false, soma aos atuais. clearErrors() limpa tudo; com nome, só o campo.

addFiles(nome, arquivos) · removeFile(nome, id) · removeExisting(nome, id, removido?)

Manipulam a lista interna de um campo de arquivo. removeExisting sem o terceiro argumento alterna.

pauseUpload(nome?) · resumeUpload(nome?) · getUploadSession(nome?)

Upload em partes (requer o módulo). As duas primeiras devolvem Promise<boolean>; getUploadSession devolve na hora a lista de sessões.

cancelJob()

cancelJob(): Promise<true>

Pede ao servidor para cancelar o processamento (DELETE em cancel_url). Erro se não houver cancel_url ou se o servidor recusar.

field(nome) · has(nome) · hasError(nome) · firstError(nome)

<small x-show="$form.hasError('email')" x-text="$form.firstError('email')"></small>
<span x-show="$form.field('email')?.remote === 'pending'">verificando…</span>

refresh() · clearRemoteCache(nome?) · diagnostics() · destroy()

refresh(): redescobre os campos. clearRemoteCache(): esquece respostas da validação remota. diagnostics(): { configErrors, cycles, fields } com regras, máscara e dependências de cada campo — útil no console. destroy(): desliga o formulário e limpa tudo que a biblioteca criou.
