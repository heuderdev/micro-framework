Rascunho automático

Guardar o que a pessoa digitou no navegador e devolver ao reabrir a página — para formulários longos, quedas de conexão e abas fechadas sem querer. Requer alpine-form-rascunho.

Instalação

Com &lt;script&gt;
<script src="/js/alpine-form/alpine-form.min.js"></script>
<script src="/js/alpine-form/alpine-form-rascunho.min.js"></script>   <!-- depois do núcleo -->
<script defer src="/js/alpine.min.js"></script>                       <!-- Alpine por último -->
Com bundler (ESM)
import AlpineFormPlugin, { AlpineForm } from 'alpine-form'
import rascunho from 'alpine-form/rascunho'

AlpineForm.use(rascunho)
Alpine.plugin(AlpineFormPlugin)

Arquivos gerados no build: dist/alpine-form-rascunho.min.js (3,5 KiB; 1,5 KiB com gzip), .js (legível) e .esm.js.

Uso básico

Marque o formulário com data-form-rascunho. Ele precisa de id — é o id que identifica o rascunho no navegador.

<form id="cadastro" x-data x-form action="/api/clientes" method="post" data-form-rascunho novalidate>
    <input name="nome" data-form-v="required|min:3">
    <input name="email" type="email" data-form-v="required|email">
    <input name="cpf" data-form-mask="cpf" data-form-v="required|cpf">
    <textarea name="mensagem"></textarea>
    <input name="senha" type="password" data-form-v="required|min:8">
    <button type="submit">Enviar</button>
</form>
  1. A pessoa digita; 400 ms depois que ela para, os campos são gravados em localStorage com a chave alpineform:rascunho:cadastro.
  2. Ela fecha a aba, a internet cai ou o navegador trava.
  3. Ao reabrir a página, os campos voltam preenchidos — sem disparar validação, sem marcar erros.
  4. Quando o envio dá certo (ou ela clica em "Limpar"/reset), o rascunho é apagado. Se o envio falhar, o rascunho continua.

Funciona com texto, textarea, select, select múltiplo, radio, checkbox, grupos de checkbox, campos com máscara (voltam formatados) e componentes próprios. Exemplo executável: examples/rascunho.php.

O que nunca é guardado

CampoPor quê
type="password"Senha não pode ficar no navegador.
data-form-sensitiveVocê marcou como sensível (CVV, token, código…).
type="file"O navegador não permite guardar nem devolver arquivos.
data-form-rascunho-ignorarVocê escolheu deixar de fora.
Campos desabilitadosNão fazem parte do envio.
<input name="cartao_cvv" data-form-sensitive data-form-v="required|digits:3">
<input name="observacao_interna" data-form-rascunho-ignorar>

Se o navegador tiver um rascunho antigo com um desses campos (ou com campos que não existem mais na página), eles são ignorados na restauração.

Opções

AtributoOndeEfeito
data-form-rascunho<form>Liga o rascunho, válido por 7 dias.
data-form-rascunho="2"<form>Validade em dias (1 a 365). Rascunho vencido é apagado ao abrir a página.
data-form-rascunho-sessao<form>Usa sessionStorage: o rascunho sobrevive a recarregar a página, mas some ao fechar a aba.
data-form-rascunho-ignorarcampoDeixa o campo de fora.
data-form-storage="none"<form>Desliga o rascunho por completo (nem lê, nem grava).
Rascunho só enquanto a aba estiver aberta, por 1 dia
<form id="pedido" x-data x-form action="/api/pedidos" method="post" data-form-rascunho="1" data-form-rascunho-sessao novalidate>

O id é a chave: dois formulários com o mesmo id (em páginas diferentes) compartilham o rascunho. Use ids únicos, por exemplo incluindo o registro em edição: id="cliente-42".

Avisar que o rascunho foi recuperado

<form id="contato" x-data="{ recuperado: false, quando: '' }" x-form action="/api/contato" method="post" data-form-rascunho
      @form:rascunho-restaurado="recuperado = true; quando = new Date($event.detail.salvoEm).toLocaleString('pt-BR')"
      @form:rascunho-apagado="recuperado = false" novalidate>

    <p x-show="recuperado" role="status">
        Recuperamos o que você tinha preenchido em <span x-text="quando"></span>.
        <button type="button" @click="$form.reset()">Começar do zero</button>
    </p>

    <input name="nome" data-form-v="required">
    <textarea name="mensagem" data-form-v="required"></textarea>
    <button type="submit">Enviar</button>
</form>
EventoQuandodetail
form:rascunho-restauradoCampos foram preenchidos a partir do rascunho (ao abrir a página){ salvoEm, campos } — data em milissegundos e nomes restaurados
form:rascunho-salvoRascunho gravado{ campos }

Pelo código

AlpineForm.rascunho.salvar('cadastro')       // grava agora, sem esperar
AlpineForm.rascunho.ler('cadastro')          // { salvoEm, valores } ou null
AlpineForm.rascunho.descartar('cadastro')    // apaga (aceita o id ou o elemento <form>)
Botão "Descartar rascunho"
<button type="button" @click="AlpineForm.rascunho.descartar($root)">Descartar rascunho</button>

Linhas dinâmicas (x-for)

A restauração preenche os campos que existem quando a página abre. Linhas criadas depois (por "Adicionar item") não recebem valores. Se o número de linhas também precisa voltar, guarde-o você mesmo e recrie as linhas antes de o formulário iniciar — ou use o rascunho só nos campos fixos e data-form-rascunho-ignorar nas linhas.

Segurança e privacidade

Atenção em dados pessoais e financeiros

O armazenamento do navegador não é cifrado: qualquer script da página consegue ler, e em computador compartilhado a próxima pessoa veria o que ficou guardado (pesa também na LGPD). Em páginas de banco ou com dados de clientes:

  • prefira não usar; se usar, ative data-form-rascunho-sessao (some ao fechar a aba) e um prazo curto (data-form-rascunho="1");
  • marque com data-form-rascunho-ignorar tudo que identifica o cliente (CPF, conta, valores);
  • para proibir em todo o site: AlpineForm.configure({ storage: 'none' }) — o módulo não lê nem grava nada, mesmo com data-form-rascunho.

O que o módulo já garante: senhas, campos sensíveis e arquivos nunca são gravados; o rascunho é apagado no sucesso e no reset; com storage: 'none' ele fica inerte. Ver também Segurança.

Problemas comuns

SintomaCausa e solução
Formulário não inicializa: "data-form-rascunho exige um id no <form>"Dê um id ao form.
"data-form-rascunho="…" inválido"Use o atributo sem valor ou um número de dias entre 1 e 365.
"Atributo desconhecido "data-form-rascunho-ignorar""O módulo alpine-form-rascunho não foi carregado (ou foi carregado depois do Alpine).
Nada é guardadoMódulo não carregado (sem ele, data-form-rascunho no form não tem efeito); storage: 'none' ativo; navegador em modo que bloqueia armazenamento.
Um campo não voltaÉ senha, sensível, arquivo, ignorado, estava desabilitado, ou foi criado depois do carregamento (linha dinâmica).
O rascunho volta depois de enviarO envio falhou (o rascunho só some no sucesso). Confira $form.phase.
