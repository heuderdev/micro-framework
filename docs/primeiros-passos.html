Primeiros passos

Um formulário de contato completo, do HTML ao PHP que responde, explicando o que acontece em cada etapa.

1. A página

contato.html
<!doctype html>
<html lang="pt-BR">
<head>
    <meta charset="utf-8">
    <title>Contato</title>
    <link rel="stylesheet" href="/js/alpine-form/alpine-form.css">
    <script src="/js/alpine-form/alpine-form.min.js"></script>
    <script src="/js/alpine-form/alpine-form-masks.min.js"></script>
    <script defer src="/js/alpine.min.js"></script>
</head>
<body>
<form id="contato" x-data x-form action="/contato.php" method="post" novalidate>
    <div>
        <label for="nome">Nome</label>
        <input id="nome" name="nome" autocomplete="name" data-form-v="required|min:3|max:120">
    </div>
    <div>
        <label for="email">E-mail</label>
        <input id="email" name="email" type="email" data-form-v="required|email">
    </div>
    <div>
        <label for="telefone">Telefone</label>
        <input id="telefone" name="telefone" data-form-mask="telefone_br" data-form-v="telefone"
               data-form-submit-value="raw">
    </div>
    <div>
        <label for="mensagem">Mensagem</label>
        <textarea id="mensagem" name="mensagem" data-form-v="required|min:10|max:2000"></textarea>
    </div>

    <button type="submit" :disabled="$form.submitting">Enviar</button>
    <p data-form-status aria-live="polite"></p>
    <p x-show="$form.success" x-text="$form.result && $form.result.message"></p>
</form>
</body>
</html>
  • x-data faz o Alpine processar o form; x-form liga o AlpineForm a ele.
  • novalidate desliga as mensagens nativas do navegador (as do AlpineForm as substituem).
  • O telefone não tem required: é opcional, mas se preenchido precisa ser válido.
  • $form é o estado do formulário, disponível em qualquer expressão Alpine dentro dele.

2. O PHP que responde

contato.php
<?php
header('Content-Type: application/json; charset=utf-8');

$nome = trim($_POST['nome'] ?? '');
$email = trim($_POST['email'] ?? '');
$telefone = preg_replace('/\D+/', '', $_POST['telefone'] ?? '');
$mensagem = trim($_POST['mensagem'] ?? '');

$errors = [];
if (mb_strlen($nome) < 3) {
    $errors['nome'][] = 'Informe seu nome.';
}
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    $errors['email'][] = 'Informe um e-mail válido.';
}
if ($telefone !== '' && !preg_match('/^\d{10,11}$/', $telefone)) {
    $errors['telefone'][] = 'Telefone inválido.';
}
if (mb_strlen($mensagem) < 10) {
    $errors['mensagem'][] = 'Escreva pelo menos 10 caracteres.';
}

if ($errors) {
    http_response_code(422);
    echo json_encode(['success' => false, 'message' => 'Confira os campos destacados.', 'errors' => $errors]);
    exit;
}

// ... grava ou envia o e-mail ...

echo json_encode(['success' => true, 'message' => 'Mensagem enviada. Obrigado!', 'data' => ['protocolo' => 1234]]);

O servidor valida de novo e responde sempre JSON. As chaves de errors são os name dos campos: cada mensagem aparece embaixo do campo correspondente.

3. O que acontece, passo a passo

  1. Página carrega. Os quatro campos são descobertos. Nenhum erro aparece.
  2. A pessoa digita "Jo" no nome e sai do campo. Aparece "Digite pelo menos 3 caracteres." abaixo do input, que recebe aria-invalid="true" e a classe af-invalid.
  3. Ela volta e completa "João". Ao parar de digitar (200 ms), o erro some.
  4. Digita 11987654321 no telefone. A máscara mostra (11) 98765-4321.
  5. Clica em Enviar com a mensagem vazia. Todos os campos são validados; o foco vai para "Mensagem", que mostra "O campo Mensagem é obrigatório." (o nome vem do <label>). Nada é enviado.
  6. Corrige e envia. O botão é desabilitado ($form.submitting), o status mostra "Enviando…" e o POST sai com telefone=11987654321 (sem máscara, por causa de data-form-submit-value="raw").
  7. Servidor responde 200. O status mostra "Mensagem enviada. Obrigado!" e $form.success fica true.
  8. Ou responde 422. Cada mensagem de errors aparece no campo; o foco vai para o primeiro com erro. Ao editar o campo, o erro do servidor some.

4. Melhorias comuns

Mensagens próprias, rótulo e limpar após sucesso
<form id="contato" x-data x-form action="/contato.php" method="post"
      data-form-reset-on-success novalidate>
    <input name="nome" data-form-v="required|min:3"
           data-form-label="seu nome"
           data-form-msg.required="Como podemos te chamar?"
           data-form-msg.min="Use pelo menos :min letras.">
    ...
</form>
Reagir ao sucesso com Alpine
<form x-data="{ enviado: false }" x-form action="/contato.php" method="post"
      @form:success="enviado = true" novalidate>
    <template x-if="!enviado">
        <div> ... campos ... </div>
    </template>
    <p x-show="enviado">Recebemos sua mensagem!</p>
</form>
